# Street Smart / #textwhenyougethome

A community archive of real-world safety habits, walks, observations, and stories.

## Development

You need Node.js and npm to run this project locally.

```sh
npm i
npm run dev
```

## Tech Stack

- TanStack Start
- React
- TypeScript
- Tailwind CSS
- Wix Headless CMS (requires `VITE_WIX_CLIENT_ID` configuration)
